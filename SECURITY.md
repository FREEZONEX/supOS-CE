# Security Policy

## Supported versions

Security fixes are provided for the latest released version of Tier0 Edge.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Use GitHub private vulnerability reporting for this repository when it is available, or contact the repository maintainers directly. Include a clear description, affected version, reproduction steps, and the potential impact. Do not include credentials, private keys, or production data in the report.

We will acknowledge a report, assess its impact, and coordinate a fix before public disclosure.
